# Smart Schedule

締切・重要度・所要時間・実施可能期間・空き時間・延期回数をもとに、その日の時間割を自動作成するスケジュール管理Webアプリです。

## 主な機能
- タスク登録（内容、締切、重要度5段階、所要時間、カテゴリ、作業の重さ）
- 実施方法：日時固定 / 日付指定 / 期間指定 / おまかせ
- 期間指定：開始日〜終了日の間、完了するまで毎日候補表示
- 自動スケジューリング
- 分割可能タスクと最低作業単位
- 1日の最大作業時間
- 今日の時間割 / 今日のTODO / 次にやること
- 繰り返し：毎日 / 平日 / 土日 / 曜日指定
- 延期回数の記録と優先度への反映
- 「今日はここまで」による未完了処理
- 90分以上の連続作業に自動休憩
- ブラウザ内自動保存
- JSONバックアップ / 復元

## 使い方

### 1. 最初に作業可能時間を設定
「設定」タブで、普段タスクを入れてよい時間を設定します。

例：
- 平日 16:00〜23:00
- 土日 09:00〜23:00

### 2. タスクを登録
右上の「＋ タスク追加」を押し、タスク名・重要度・所要時間・実施方法を入力します。

### 3. 実施方法
- **日時固定**：指定日時に固定します。
- **日付指定**：指定日の空き時間へ配置します。
- **期間指定**：例 10/7〜10/10。期間中は完了するまで毎日候補として表示されます。
- **おまかせ**：締切までの空き時間へ自動配置します。

### 4. 分割可能タスク
長いタスクは「分割可能」をONにすると、最低作業単位と1日の最大作業時間を守って分割配置します。

### 5. 今日画面
今日画面には次が表示されます。
- 今日の予定時間
- 完了件数
- 今日必須の件数
- 空き時間
- 次にやること
- 今日の時間割
- 今日のTODO

### 6. 完了
時間割またはTODOの「完了」を押します。
分割タスクでは、その枠の時間ぶんだけ残り時間が減ります。

### 7. 延期
「延期」を押すと延期回数を記録し、自動配置時の優先度が上がります。

### 8. 今日はここまで
「今日はここまで」を押すと、未完了タスクを翌日以降の再配置対象として扱います。

## 自動配置の基本方針
1. 固定予定
2. 今日やらないと締切に間に合わないタスク
3. 実施期間の終了が近いタスク
4. 締切が近いタスク
5. 重要度が高いタスク
6. 延期回数が多いタスク

残り作業時間 ÷ 残り実施可能日数を基準に、その日に必要な作業量を計算し、締切直前に偏らないよう少し前倒しで配置します。

## データ保存
この初期版ではデータをブラウザの localStorage に保存します。同じPC・同じブラウザでは自動的に保持されます。
別端末へ移す場合は「設定」からJSONを書き出し、移行先で読み込んでください。

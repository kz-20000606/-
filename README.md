# Smart Schedule

タスクを「付箋」のように扱い、自分で1日の時間割へ配置していくスケジュール管理Webアプリです。

## 基本コンセプト

このアプリは、アプリ側が自動で1日の時間割を決めるのではなく、

1. 今日対象のタスクを小さな付箋として表示
2. 自分で時間割へドラッグ
3. 時間割上で後から並び替え

という使い方をします。

## 主な機能

- タスク登録
  - タスク名
  - メモ
  - カテゴリ
  - 重要度（5段階）
  - 所要時間
  - 締切
- 実施方法
  - 日時固定
  - 日付指定
  - 期間指定
  - 締切まで候補
- 今日のタスク置き場
  - 今日が実施対象のタスクだけを表示
  - すべて同じ小さなサイズの付箋として表示
- 手動時間割
  - 付箋を時間割へドラッグして配置
  - 配置後も上下ドラッグで時刻変更
  - 30分前 / 30分後ボタン
  - 「戻す」でタスク置き場へ戻す
- 所要時間に比例した表示
  - 15分 → 15分ぶん
  - 30分 → 30分ぶん
  - 60分 → 1時間ぶん
  - 90分 → 1時間30分ぶん
- 繰り返し
  - 毎日
  - 平日のみ
  - 土日のみ
  - 曜日指定
- 完了・延期
- ブラウザ内自動保存
- JSONバックアップ / 復元

## 使い方

### 1. 表示時間を設定

「設定」で時間割に表示する時間帯を設定します。

例：
- 平日 16:00〜23:00
- 土日 09:00〜23:00

### 2. タスクを登録

「＋ タスク追加」を押して登録します。

### 3. 実施方法

#### 日時固定
指定した日時に直接時間割へ表示します。

#### 日付指定
指定日に「今日のタスク置き場」へ表示します。

#### 期間指定
例：10/7〜10/10

期間中は、完了するまで毎日「今日のタスク置き場」へ表示します。

#### 締切まで候補
開始可能日以降、締切まで候補として表示します。

### 4. 時間割を作る

「今日のタスク置き場」に並んでいる小さな付箋を、下の時間割へドラッグします。

付箋置き場ではすべて同じサイズですが、時間割へ置くと所要時間に応じてカードの高さが変わります。

### 5. 後から時刻を変更

時間割上の「⋮⋮」をつかんで上下に動かすと、30分単位で時刻を変更できます。

「戻す」を押すと時間割から外して、タスク置き場へ戻せます。

## 自動配置について

現在の仕様では、自動時間割作成と自動休憩挿入は行いません。

時間割はユーザーが付箋を自分で配置して作成します。

## データ保存

データはブラウザの localStorage に保存されます。
別端末へ移す場合は、設定画面からJSONを書き出して読み込んでください。


## 自由メモ・付箋ボード

今日の時間割画面は左右に分かれています。

- 左：時間割
- 右：自由メモスペース

右側はグリッドのない白紙です。

「＋ 付箋を作成」から、付箋に書く内容と色を設定できます。

色は以下の4色です。

- 赤
- 黄
- 緑（初期値）
- 青

作成後の付箋は、上部のバーをドラッグして好きな位置へ移動できます。
右下をドラッグすると大きさを自由に変更できます。
位置・大きさ・内容・色はブラウザ内に保存されます。

付箋の「編集」から内容や色の変更、削除もできます。
